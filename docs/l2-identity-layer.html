S1 — Video reconcile (character observation)

File: sublayers/s1_video_reconcile.py · Core: character_observation.py

Step 1 / 6

1. Sample frames

sampling.sample_timestamps_for_utterance()

  • Prefer 3-word chunks from AssemblyAI words[] timestamps
  • Fallback: ~1 fps uniform samples inside utterance [start, end]

2. Detect faces

collect_observations() reads video frame at each sample time.

  • Primary: InsightFace ArcFace (buffalo_l, CPU)
  • Fallback: MediaPipe face + histogram embedding
  • Quality gate: conf ≥ 0.72, bbox ≥ 36px, aspect 0.55–1.6

3. Cluster → char_1, char_2, …

_assign_character_ids()

  1. Online match by embedding (ArcFace threshold 0.38)
  2. Merge tracks that never co-occur in same frame (0.36)
  3. Appearance merge: hair+skin HSV histogram (0.86 / 0.92 strong)
  4. Consolidate to max on-screen character count

4. Speaker → character votes

_speaker_character_votes() — when speaker X talks, which face is visible?

dominant_character_per_speaker() picks highest-weight char_* per A/B/C.

note Two speakers can map to the same character (e.g. A→char_2, C→char_2). Labels are not merged.

5. Annotate utterances

annotate_utterances_with_characters()

  • Adds character_id on each utterance
  • Does not change speaker

6. Portraits

build_video_faces_from_observations()

  • Best upper-body crop per char_*
  • Copied once per diarization speaker that maps to that character
  • Path: output/assets/<run>/speakers/{A,B,C}/portrait.jpg

note Same JPEG duplicated if two speakers share one character.
